# 5/17/2026 3 PM - Big challenge

_Time spent: 1h_

I have faced a very big challenge, cuz the tp4056 board to charge the battery has an input, and an output. I was initially thinking about having the input connected to the vbus on the esp32 c3 mini, and then the B+ to battery positive and B- to battery negative. The output + and minus would then in theory be shorted to vbus and gnd, which would result in the input and ooutput getting shorted.

![IMG_20260508_175743](https://stasis.hackclub-assets.com/images/1779032350236-j9akjm.jpg)


I did some research, and found out that if i did so, there would then not be any battery circuit protection, so it wouldnt work, and it was really not recommended to do so. I also dont want to have two usb-c ports, one for charging and one for uploading code.

However, idk an idea just pop into my mind that if i switch the esp32 c3 mini board and the tp4056 position, then i could in theory use the tp4056 as the first input and then the c3 mini on the side. That is what i did, however the downside is now that if i want to upload a code, ive gotta open up the backcover to plug in the usb, but i dont think i will be doing it every day. Now i have the battery protection and working c3 mini on battery.

![IMG_20260508_195654](https://stasis.hackclub-assets.com/images/1779032477036-kp6gqi.jpg)

I also forgot to mention that i added the switch on the front directly to the battery, so the c3 mini doesnt have power all the time. So now if i want it to turn on, switch the front switch on, and it makes it power on.
